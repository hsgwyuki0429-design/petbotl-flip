# ペットボトルフリップ！ 🍾

2D の物理演算ペットボトルフリップゲーム。ブラウザだけで遊べます(サーバー不要)。

## 遊び方

1. `index.html` をブラウザで開く
2. **長押し**(タップ or スペースキー)でパワーをチャージ — ゲージは往復するのでタイミングが大事!
3. **離す**とボトルがフリップ!
4. きれいに**直立**で着地させよう

## ルール

- 🍾 **直立着地** … +1点(コンボで倍率アップ)
- 🧢 **キャップ着地**(逆立ち)… +5点の大ボーナス!
- 💥 倒れたらコンボはリセット
- 📈 10点ごとにレベルアップ — 回転が速くなってタイミングがシビアに
- 🏆 ベストスコアは自動保存(localStorage)

## 技術

- 素の HTML / CSS / JavaScript(依存ライブラリなし)
- Canvas 2D 描画
- 角インパルス法による剛体物理(バウンド・転倒・よろめきをシミュレート)
- ボトル内の水のスロッシング表現
- WebAudio による効果音
- モバイルタッチ対応
